# Evidence

The E in SPADE. What you look things up in: research, notes from talks and
courses, reference material, and templates (in `templates/`). Things worth
keeping that you are not acting on right now.

Dig up the evidence, make the call, record it in `decisions/`. If you find
yourself acting on it, it has become a project.
