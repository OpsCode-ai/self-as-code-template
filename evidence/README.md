# Evidence

The E in SPADE. What you look things up in and cite: research, extractions,
reference, and templates (in `templates/`). Things worth keeping that you are
not acting on right now.

Dig up the evidence, make the call, record it in `decisions/`. If you find
yourself acting on it, it has become a project.
