# Your days

One file a day. `current.md` is today. Older days sit beside it, named by
date, like `2026-10-27.md`.

`/done` writes today down at the end of a session. `/start` reads it back at
the start of the next one, on any machine. `/task-bridge` adds a note any
time you step away. `usage.md` here is what your sessions cost, refreshed by
`/done`.

This is your own private space, so these days are yours alone. In a
business, the same log lives under `team/<you>/`, where everyone who works
there can read it.
