# A dashboard, drawn for me

Reads first: `vision.md`, `standards/brand.md`, then `standards/voice.md`
for every word on it.

- An app, not a document. A menu down the left, like any software I use,
  each item with an icon from my one icon set (`scripts/lib/library/`). On a
  phone the menu folds into a Menu button at the top, and the page still
  reads at phone width.
- It opens on my timeline: the future me at 20 years, then 10, 5, 2 and 1
  year (the ones my plan has), six months, my next review, this week,
  tomorrow and every day. Across the page on a laptop, down it on a phone.
  Under it, this week and my floor side by side. Then the rest, in the order
  my plan has it. `/sac dashboard` draws exactly this.
- If I want it on my phone, it can be published as a private Claude artifact,
  and only on my yes: until then nothing leaves this laptop.
- My ink, my paper, my one accent, my typeface. Nothing else. Plain black on
  white if I have not chosen.
- Numbers in small tables or on their own line, each saying where it came
  from. No gauges, no dials, no number made up to fill a tile.
- Space, not boxes. No panel inside a panel. No code font for ordinary
  words. It is a page made for me, not the page every AI tool makes.
- Gentle movement, and none if my computer asks for less.
- Checked before it is shown to me: the colours on the page are the ones in
  `brand.md` (`python3 scripts/oac-vision.py check <page>`), and the words
  pass the same two checks as an email.
