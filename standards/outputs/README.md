# Outputs: one standard per kind

One page per kind of thing that gets made for you: an email, a report, a
page, an app. Each one says what it reads first (how you sound, what you like
to look at), what it must never do, and how it is checked. Add a kind when
you need one. Nothing made for you may look or sound like a machine made it.
