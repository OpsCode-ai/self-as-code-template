## Never

Nothing made for me looks like it came off the shelf. It is made for me: my
words, my colours, my name at the top. Never the look every AI tool makes
(what people call vibe-coded): the purple fade, the same rounded cards, the
same font on every page, a badge on everything, a glow, dark panels with
bright green text, code font for ordinary words. One accent colour, not
three. Space, not boxes.
