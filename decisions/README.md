# Decisions

The D in SPADE. One numbered file per decision you make:
`NNN-short-slug.md` with `status: proposed | accepted | superseded`.
Write down the why, not just the what, so you never have to argue a settled
choice again.

Dig up the evidence (in `evidence/`), make the call, record it here.
